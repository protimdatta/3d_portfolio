# My Full-Stack Development Learning Journey

When I started my Diploma in Computer Science & Technology at Cox's Bazar Model Polytechnic Institute, I had no idea how deep the rabbit hole of web development would go. What began as coursework assignments turned into a genuine passion for building things that work.

## The Beginning: HTML & CSS

My first real encounter with code was in the lab, writing HTML tables and CSS layouts. I remember the frustration of centering a div (we've all been there) and the pure joy when `display: flex` finally clicked. Those early days taught me that structure matters — semantic HTML isn't just about accessibility, it's about writing code that makes sense six months later.

## JavaScript: The Language That Changed Everything

Learning JavaScript ES6+ was a turning point. Arrow functions, destructuring, async/await — these weren't just syntax sugar, they changed how I thought about solving problems. I started building small interactive components: form validators, dynamic content loaders, simple games. Each project taught me something new about the event loop, closures, and why `this` behaves the way it does.

## The Backend Awakening

PHP and MySQL came next in the curriculum. Building CRUD applications with raw SQL queries gave me a deep appreciation for how data actually moves. Then I discovered Node.js and Express.js — writing JavaScript on both frontend and backend felt like a superpower. REST APIs, middleware, authentication — concepts that seemed abstract in lectures became concrete when I built them myself.

## MongoDB and the MERN Stack

Chirkut Ghor, my personal e-commerce project, was where everything came together. React on the frontend, Node.js/Express on the backend, MongoDB for data. I learned the hard way about:
- Proper error handling (not just `console.log`)
- Database indexing and query optimization
- State management as the app grew
- Deployment pipelines and environment variables

## Where I Am Now

Currently in my 6th semester, I'm expanding into Python and Django while keeping my JavaScript skills sharp. The goal hasn't changed: become a professional Software Engineer. But the path has become clearer — build real things, break them, fix them, repeat.

## What's Next

- Deepen my understanding of system design
- Contribute to open source
- Build more complex distributed systems
- Maybe write more blog posts about the journey

The learning never stops. And honestly, that's the best part.
